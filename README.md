# Granulocyte WBC Reader
Educational MLT web app for Neutrophil, Eosinophil and Basophil morphology practice.

## Files
index.html, style.css, app.js, manifest.json, sw.js, assets/comparator.jpg

## Deploy
Upload this folder to GitHub or drag it to Netlify. No backend or API key is required.

## Important
The image matching is a simple browser-side educational heuristic, not a validated medical AI model. Stain, lighting, focus and camera conditions affect results. Do not use it for clinical diagnosis.
